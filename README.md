## 🚀 Overview

This starter kit is a foundation for high-end frontend engineering, focusing on fluid motion and architectural excellence. It leverages **Next.js 16** for performance and **GSAP** for sophisticated timeline-based animations.

### ✨ Key Features

- 🎭 **Advanced Animations**: Powered by GSAP for intricate layout transitions and component motion.
- 🌊 **Smooth Scrolling**: Integrated with **Lenis** for a premium feel.
- 🎨 **Tailwind v4**: Utilizing the latest CSS-first configuration and high-performance styling.
- 🅰️ **Custom Typography**: Premium font integration including _Poppins_ and _Roboto Slab_.
- 📱 **Fully Responsive**: Crafted for a seamless experience across all device sizes.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **UI Library**: [React 19](https://reactjs.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [GSAP](https://greensock.com/gsap/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Type**: [TypeScript](https://www.typescriptlang.org/)

## 🏗️ Project Structure

```bash
├── app/              # Next.js App Router (Pages, Components, Global CSS)
│   ├── Components/   # Reusable React Components
│   ├── gsap/         # GSAP Specific Animation Logic
│   └── globals.css   # Tailwind v4 Configuration & Base Styles
├── public/           # Static Assets (Fonts)
└── ...               # Configuration Files (PostCSS, TSConfig, etc.)
```

## 🚦 Getting Started

### Prerequisites

- Node.js (Latest LTS)
- npm or yarn

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/nabe-starter-kit.git
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

Open [http://localhost:5000](http://localhost:5000) (Custom Port) to view the project.

---

## 🎨 Design Philosophy

The project follows a **Minimalist High-Contrast** aesthetic. By combining raw layout structures with elegant motion, it creates a "digital craft" feel. The use of local fonts allows for expressive typography without sacrificing performance.
